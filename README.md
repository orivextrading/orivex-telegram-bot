# بوت Orivex على تليجرام

بوت بيرد على المتدربين بأزرار جاهزة (الكورسات، الأسعار، الأسئلة الشائعة، حالة التسجيل)
+ رد ذكي بالـ AI لأي سؤال حر مش موجود في الأزرار.

## 1) اعمل البوت على تليجرام
1. افتح تليجرام وابحث عن **BotFather**
2. ابعتله `/newbot` واتبع الخطوات (اسم البوت + username ينتهي بـ `bot`)
3. هيديك **توكن** (Token) — احفظه، ده اللي هتحطه في `.env`

## 2) اعمل مفتاح Anthropic API (للرد الذكي)
1. روح [console.anthropic.com](https://console.anthropic.com)
2. اعمل حساب → API Keys → Create Key
3. احفظ المفتاح

## 3) جهّز المشروع
```bash
npm install
cp .env.example .env
```
افتح ملف `.env` واملأ:
- `TELEGRAM_BOT_TOKEN` من BotFather
- `ANTHROPIC_API_KEY` من Anthropic Console
- باقي القيم (Supabase, الموقع, واتساب) موجودة بالفعل، غيّرها لو اتغيرت

## 4) شغّل البوت محليًا للتجربة
```bash
npm start
```
لو شفت `✅ Orivex bot is running...` يبقى شغال، جرب تكلمه على تليجرام.

## 5) ارفعه على استضافة دائمة (عشان يفضل شغال 24 ساعة)
البوت هنا شغال بنظام Polling (بيسأل تليجرام كل شوية "فيه رسايل جديدة؟")، وده بيحتاج
سيرفر شغال طول الوقت، مش استضافة استاتيك زي اللي الموقع عليها. أسهل خيارات مجانية:

- **Render.com** → New → Background Worker → اربط الملفات دي → حط متغيرات الـ `.env` في Environment Variables
- **Railway.app** → نفس الفكرة، فيه باقة مجانية بحد استخدام شهري

بعد الرفع، البوت هيفضل شغال طول الوقت من غير ما يبقى مفتوح على جهازك.

## تحديث بيانات الكورسات أو الأسئلة الشائعة
كل بيانات الكورسات والـ FAQ موجودة في ملف `academyData.js` منفصلة عن كود البوت.
لو غيّرت سعر أو ضفت سؤال في الموقع، عدّل نفس الحاجة هنا عشان البوت يفضل متزامن.

## ملاحظة عن التكلفة
- الأزرار والـ FAQ الثابتة: مجانية بالكامل
- الرد الذكي (AI): كل رسالة بتكلف جزء بسيط جدًا من السنت (بنستخدم موديل Haiku الاقتصادي).
  لو عايز ردود أدق وأذكى مقابل تكلفة أعلى شوية، غيّر السطر `model: 'claude-haiku-4-5-20251001'`
  في `index.js` إلى `'claude-sonnet-5'`.
