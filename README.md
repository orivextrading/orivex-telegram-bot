# بوت Orivex على تليجرام
 
بوت بيرد على المتدربين بأزرار جاهزة (الكورسات، الأسعار، الأسئلة الشائعة، حالة التسجيل)
+ رد ذكي بالـ AI لأي سؤال حر مش موجود في الأزرار.
## 1) اعمل البوت على تليجرام
1. افتح تليجرام وابحث عن **BotFather**
2. ابعتله `/newbot` واتبع الخطوات (اسم البوت + username ينتهي بـ `bot`)
3. هيديك **توكن** (Token) — احفظه، ده اللي هتحطه في `.env`
## 2) اعمل مفتاح Anthropic API (للرد الذكي)
1. روح [console.anthropic.com](https://console.anthropic.com)
2. اعمل حساب → API Keys → Create Key
3. احفظ المفتاح
## 3) جهّز المشروع
```bash
npm install
cp .env.example .env
```
افتح ملف `.env` واملأ:
- `TELEGRAM_BOT_TOKEN` من BotFather
- `ANTHROPIC_API_KEY` من Anthropic Console
- باقي القيم (Supabase, الموقع, واتساب) موجودة بالفعل، غيّرها لو اتغيرت
## 4) شغّل البوت محليًا للتجربة
```bash
npm start
```
لو شفت `✅ Orivex bot is running...` يبقى شغال، جرب تكلمه على تليجرام.
 
## 5) ارفعه على استضافة مجانية (Render Web Service)
 
**مهم:** البوت دلوقتي بيشتغل بنظام Webhook، يعني لازم تختار نوع الخدمة صح في Render:
 
1. روح render.com → **New +** → اختار **"Web Service"** (مش Background Worker)
2. اربطه بنفس الـ repository بتاعك على GitHub (`orivex-telegram-bot`)
3. الإعدادات:
   - **Build Command**: `npm install`
   - **Start Command**: `node index.js`
   - **Instance Type**: اختار **Free** (0 دولار شهريًا)
4. في **Environment Variables** ضيف نفس القيم اللي في `.env.example` (توكن تليجرام، بيانات Supabase، رابط الموقع، رقم الواتساب) — **ما عدا** `ANTHROPIC_API_KEY` لو لسه مش عندك، ومتضيفش `PORT` أو `RENDER_EXTERNAL_URL` بنفسك، Render بيحطهم لوحده تلقائيًا
5. دوس **"Deploy Web Service"**
بعد أول Deploy ناجح، البوت هيظبط نفسه لوحده على تليجرام (مفيش خطوة يدوية إضافية).
 
### ملحوظة عن الخطة المجانية
الخطة المجانية في Render بتـ"تنام" بعد 15 دقيقة من غير أي زيارة، وأول رسالة بعد النوم بتاخد حوالي 30-50 ثانية لحد ما البوت يصحى ويرد. لو عايز تمنع النوم ده خالص (يعني رد فوري طول الوقت) وهو برضو مجاني:
 
1. روح على uptimerobot.com واعمل حساب مجاني
2. اعمل "New Monitor" → HTTP(s) → حط رابط السيرفر بتاعك من Render (هتلاقيه فوق في صفحة الخدمة، شكله زي `https://orivex-telegram-bot.onrender.com`)
3. خليه يزوره كل 5 دقايق
كده UptimeRobot هيفضل يزور البوت بنفسه كل شوية ويمنعه ينام، من غير ما تدفع أي حاجة.
 
## تحديث بيانات الكورسات أو الأسئلة الشائعة
كل بيانات الكورسات والـ FAQ موجودة في ملف `academyData.js` منفصلة عن كود البوت.
لو غيّرت سعر أو ضفت سؤال في الموقع، عدّل نفس الحاجة هنا عشان البوت يفضل متزامن.
